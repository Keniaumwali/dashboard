# CampusFlow — School Management Dashboard

## About the Project

CampusFlow is a school management website designed to present important school information in a clean, organized dashboard.

## Features

- School home page
- Dashboard overview and statistics
- Class schedule
- Attendance summary
- Students table
- Announcements
- Teachers section
- Responsive layout for smaller screens

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive design with media queries

## Project Structure

- `index.html` — Home page
- `style.css` — Home page styling
- `dashboard.html` — School dashboard
- `dashboard.css` — Dashboard styling

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser to view the home page.
4. Open `dashboard.html` to view the dashboard.
